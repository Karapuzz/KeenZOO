**Редакция 26 от 2026-10-15**

Установочный архив:

```text
KeenZOO_full_2026-10-15-26.tar.gz
```

SHA-256 архива:

```text
de6fb1d8d14e3bcc7feda6cf67cb6ff8f9600d48e703a8da8425fe9b419beb20
```

Проверка на компьютере или роутере:


Результат должен в точности совпасть с SHA-256 выше.

## 1. Важный порядок установки

Shell-меню KeenZOO нельзя запустить, пока на роутере нет Linux-shell.
Поэтому установка с полностью чистого Keenetic выполняется в два этапа:

1. **Сначала через веб-интерфейс Keenetic устанавливается штатная
   Entware.** Она устанавливает Linux-shell и SSH-сервер Dropbear.
2. **Потом через Entware SSH загружается архив KeenZOO и запускается
   меню KeenZOO.** В меню выбирается пункт 1.

Новое меню редакции 26 содержит ровно пять пунктов:

```text
1. Новая установка KeenZOO (на роутер с Entware)
2. Обновление KeenZOO
3. Бэкап KeenZOO
4. Удаление KeenZOO
5. Выход
```

Меню больше не предлагает устанавливать Entware: такой пункт невозможно
использовать как первую операцию, если Linux-shell ещё отсутствует.

### Новое в редакции 26: защита `opkg.conf`

При установке и обновлении KeenZOO проект больше не переключает зеркало
Entware автоматически:

1. Сначала проверяются **точные штатные URL**, уже записанные в строках
   `src/gz entware` и `src/gz keendev` файла `/opt/etc/opkg.conf`.
2. Если все текущие штатные фиды доступны, файл остаётся побайтно
   неизменным. Доступность других зеркал не является причиной замены.
3. Только если текущий штатный фид недоступен, проверяются альтернативы.
4. Перед записью показываются старые и предлагаемые новые строки.
5. Для согласия нужно вручную ввести точное слово:

   ```text
   SWITCH
   ```

6. Пустой ответ, любое другое слово или запуск без интерактивного TTY
   отменяет установку/обновление до изменения `opkg.conf`.
7. После согласия меняются только `entware`/`keendev`; сторонние фиды,
   архитектурная ветка и подпуть `/keenetic` сохраняются.
8. Непосредственно перед записью создаётся актуальная копия:

   ```text
   /opt/etc/opkg.conf.bak-keenzoo
   ```

   Также сохраняется копия с меткой времени.

Откат вручную:

```sh
cp -p /opt/etc/opkg.conf.bak-keenzoo /opt/etc/opkg.conf
/opt/bin/opkg update
```

## 2. Что понадобится

- компьютер в домашней сети роутера;
- доступ к веб-интерфейсу Keenetic, обычно
  `http://192.168.1.1` или `http://my.keenetic.net`;
- USB-накопитель с разделом **ext2/ext3/ext4**;
- интернет на роутере;
- архив `KeenZOO_full_2026-10-15-26.tar.gz` на компьютере;
- терминал: Windows Terminal/PowerShell, PuTTY либо терминал macOS/Linux.

Рекомендуется не менее **150 МБ** свободного места. Это рекомендация,
а не жёсткий запрет: установщик предупреждает о малом остатке.

## 3. Установить компоненты KeeneticOS

В веб-интерфейсе откройте раздел, похожий на:

```text
Управление → Общие настройки → Обновления и компоненты
             → Изменить набор компонентов
```

Включите:

1. **Поддержка открытых пакетов** (`Open Package support`) — обязательно.
2. **Поддержка файловых систем EXT** — обязательно для ext4.
3. **SMB-сервер** — необязательно; удобен для копирования установщика
   Entware на диск с компьютера.
4. **Сервер SSH KeeneticOS** — необязательно. Это SSH к CLI прошивки,
   а не Linux-shell Entware.

Если SSH KeeneticOS установлен, он обычно занимает порт 22, а Entware
Dropbear использует порт **222**. Если прошивочный SSH не установлен,
Entware обычно использует порт **22**.

Примените изменения и дождитесь перезапуска служб.

## 4. Подготовить USB-раздел и установщик Entware

1. Подключите ext4-накопитель к роутеру.
2. Убедитесь, что он виден в разделе веб-интерфейса
   `Приложения → Диски и принтеры` или `USB-накопители`.
3. В корне раздела создайте каталог с точным именем `install`.
4. Скопируйте в этот каталог подходящий штатный EN-инсталлер Entware.

Для платформы MT7981/AArch64 используется:

```text
install/EN_aarch64-installer.tar.gz
```

Официальная загрузка:

<https://bin.entware.net/aarch64-k3.10/installer/EN_aarch64-installer.tar.gz>

Проверенный на дату инструкции SHA-256 этого EN-инсталлера:

```text
aa2e5850c47bf54360a74bab2092f5c2db01c9f001c2038c44d0559bfb3d7531
```

Проверка в PowerShell:

```powershell
Get-FileHash .\EN_aarch64-installer.tar.gz -Algorithm SHA256
```

Для роутера другой архитектуры нельзя слепо использовать AArch64-файл.
Нужный инсталлер выбирается по платформе устройства.

Не кладите архив KeenZOO в каталог `install`: туда помещается только
штатный установщик Entware.

## 5. Установить Entware через веб-интерфейс

Откройте:

```text
Приложения → OPKG / Менеджер пакетов OPKG
```

1. Выберите подготовленный ext4-раздел.
2. Разрешите пользователю доступ к службам OPKG, если есть такой пункт.
3. При первой установке оставьте `initrc` пустым/штатным.
4. Нажмите **Сохранить** и подождите несколько минут.

Проверьте системный журнал Keenetic:

```text
Управление → Диагностика → Системный журнал
```

Успешный финал обычно содержит строки:

```text
[3/5] Generating SSH keys...
[4/5] Setting timezone, script initrc and starting "dropbear"...
dropbear: Running in background
configured init script: "/opt/etc/init.d/rc.unslung"
[5/5] "Entware" installed!
```

До появления `[5/5]` к установке KeenZOO не переходите.

## 6. Подключиться именно к Entware SSH

Команды ниже вводятся в терминале компьютера, не в поле браузера.

Если установлен SSH-компонент KeeneticOS, сначала попробуйте порт 222:

```sh
ssh -p 222 root@192.168.1.1
```

Если прошивочный SSH не установлен, обычно используется порт 22:

```sh
ssh root@192.168.1.1
```

Для штатной первичной установки Entware обычно действуют:

```text
логин:  root
пароль: keenetic
```

Сразу после первого входа смените пароль:

```sh
passwd
```

Правильный Linux-shell выглядит примерно так:

```text
~ #
```

или:

```text
/ #
```

Если приглашение выглядит как `(config)>`, вы вошли в CLI прошивки
Keenetic под `admin`. Выполните `exit` и подключитесь к другому порту
под пользователем `root`.

Проверьте Entware:

```sh
mount | grep ' /opt '
/opt/bin/opkg --version
/opt/bin/opkg update
```

Если `/opt` не смонтирован или `opkg update` падает, сначала исправьте
Entware. KeenZOO пока не устанавливайте.

## 7. Передать архив KeenZOO на роутер

`scp` запускается **на компьютере в отдельном терминале**, а не внутри
SSH-сессии роутера.

### Windows PowerShell, Entware на порту 222

```powershell
scp.exe -O -P 222 .\KeenZOO_full_2026-10-15-26.tar.gz root@192.168.1.1:/tmp/
```

### Windows PowerShell, Entware на порту 22

```powershell
scp.exe -O .\KeenZOO_full_2026-10-15-26.tar.gz root@192.168.1.1:/tmp/
```

### macOS/Linux, порт 222

```sh
scp -O -P 222 KeenZOO_full_2026-10-15-26.tar.gz root@192.168.1.1:/tmp/
```

У `ssh` порт задаётся маленькой `-p`, у `scp` — большой `-P`.
Параметр `-O` включает старый SCP-протокол, совместимый с Dropbear.
Если старая версия `scp` не знает `-O`, уберите только этот параметр.

В WinSCP выберите протокол **SCP**, IP роутера, порт Entware,
пользователя `root` и каталог назначения `/tmp`.

## 8. Проверить, распаковать и запустить меню

Вернитесь в SSH-сессию Entware и выполните:

```sh
ls -lh /tmp/KeenZOO_full_2026-10-15-26.tar.gz
sha256sum /tmp/KeenZOO_full_2026-10-15-26.tar.gz
```

Ожидаемый SHA-256:

```text
de6fb1d8d14e3bcc7feda6cf67cb6ff8f9600d48e703a8da8425fe9b419beb20
```

После совпадения хэша:

```sh
rm -rf /tmp/kz
mkdir -p /tmp/kz
tar xzf /tmp/KeenZOO_full_2026-10-15-26.tar.gz -C /tmp/kz
sh /tmp/kz/opt/bin/entware_bootstrap.sh
```

Появится меню 1–5. Для первой установки проекта выберите:

```text
1
```

Пункт 1 проверит, что Entware готова и KeenZOO ещё не установлен, затем
запустит `deploy_bypass.sh` с архивом. Дождитесь завершения всех этапов.
Не закрывайте терминал во время установки.

Если KeenZOO уже найден, пункт 1 безопасно откажет и предложит пункт 2.

### Необязательный внешний лаунчер

Если вместе с релизом отдельно получен `KeenZOO_menu.sh`, можно положить
его рядом с архивом и вместо распаковки меню выполнить:

```sh
sh /tmp/KeenZOO_menu.sh
```

Он показывает те же пять пунктов. Для установки из одного FULL-архива
достаточно основного способа через `opt/bin/entware_bootstrap.sh` выше.

## 9. Заполнить конфигурацию проекта

При первой установке deploy предупредит о плейсхолдерах. Откройте:

```sh
vi /opt/etc/bot/bot_config.py
```

Минимально замените значения:

```python
token = 'ТОКЕН_ОТ_BOTFATHER'
allowed_user_ids = [ВАШ_ЧИСЛОВОЙ_TELEGRAM_ID]
usernames = ['ВашUsername']
web_password = 'НАДЁЖНЫЙ_ПАРОЛЬ_ПАНЕЛИ'
```

Кавычки вокруг строк обязательны. В `vi`: `i` — редактирование;
`Esc`, затем `:wq` и Enter — сохранить и выйти.

Проверьте синтаксис и перезапустите сервисы:

```sh
cd /opt/etc/bot
python3 -c 'import bot_config; print("bot_config OK")'
/opt/etc/init.d/S99generator restart
/opt/etc/init.d/S99telegram_bot restart
```

Веб-панель:

```text
http://192.168.1.1:8080
```

Имя пользователя панели — `admin`, пароль — `web_password`.
Не публикуйте порт 8080 в Интернет: панель использует HTTP. Для
недоверенной сети применяйте VPN или SSH-туннель.

## 11. Обновление KeenZOO — пункт 2

Скачайте новый FULL-архив на компьютер, сверьте опубликованный SHA-256 и
передайте архив в `/tmp`. Пример для порта 222:

```sh
scp -O -P 222 KeenZOO_full_ГГГГ-ММ-ДД-РЕД.tar.gz root@192.168.1.1:/tmp/
```

На роутере **обязательно запустите меню из нового архива**, а не старую
установленную копию. Только свежий `deploy_bypass.sh` содержит актуальные
preflight-проверки и запрос согласия на изменение зеркала:

```sh
rm -rf /tmp/kz
mkdir -p /tmp/kz
tar xzf /tmp/KeenZOO_full_ГГГГ-ММ-ДД-РЕД.tar.gz -C /tmp/kz
sh /tmp/kz/opt/bin/entware_bootstrap.sh
```

Пункт 2 выбирает `deploy_bypass.sh`, расположенный рядом с новым
`entware_bootstrap.sh`, то есть из распакованного релиза.

Выберите:

```text
2
```

Меню откажет, если не найдёт установленный проект или FULL-архив.
Архив выбирается по числовому номеру редакции, а не лексикографически.
После обновления повторите проверки из раздела 10.

## 12. Бэкап KeenZOO — пункт 3

Запустите установленное меню:

```sh
sh /opt/bin/entware_bootstrap.sh
```

Выберите:

```text
3
```

Штатный `backup_project.sh` создаёт архив обычно в `/opt/backups`, а при
невозможности — в `/tmp`. В финале скрипт напечатает точное имя и
команду `scp` для копирования на компьютер.

Прямой эквивалент:

```sh
sh /opt/bin/backup_project.sh
```

Перед обновлением и особенно перед удалением рекомендуется скопировать
полученный архив с роутера на компьютер.

## 13. Удаление KeenZOO — пункт 4

Сначала сделайте бэкап пунктом 3. Затем:

```sh
sh /opt/bin/entware_bootstrap.sh
```

Выберите:

```text
4
```

Меню вызывает:

```sh
sh /opt/bin/deploy_bypass.sh -remove
```

Внутренний удаляльщик задаст отдельный вопрос:

```text
Проект будет удалён полностью (файлы, правила, ipset). Продолжить? [y/N]:
```

Для подтверждения введите `y`. Любой другой ответ отменяет операцию.

Удаляются сервисы, правила, ipset и файлы KeenZOO. **Entware остаётся**;
её `opkg` и установленные пакеты автоматически не удаляются. После
успешного удаления рекомендуется перезагрузить роутер.

## 15. Прямой bootstrap Entware для специального случая

Режим с явным путём сохранён для администратора, у которого уже есть
другой Linux-shell, но Entware ещё не развёрнута:

```sh
sh /tmp/kz/opt/bin/entware_bootstrap.sh /opt
```

или для точки монтирования USB:

```sh
sh /tmp/kz/opt/bin/entware_bootstrap.sh /tmp/mnt/<метка>
```

Это **не пункт интерактивного меню** и не основной путь установки с
чистого Keenetic. Без Linux-shell используйте веб-установку Entware из
разделов 3–5.

Bootstrap принимает только `/opt` либо `/tmp/mnt/<метка>`, проверяет
mountpoint и тип файловой системы ext2/3/4. Для старых TLS-less систем
HTTP-загрузка tar-инсталлера требует явный
`KEENZOO_BOOTSTRAP_SHA256=<хэш>`; без пина установка отказывает.

`KEENZOO_BOOTSTRAP_NO_HTTP=1` запрещает HTTP для собственного загрузчика
bootstrap. Последующий `opkg` использует системный wget Entware; при
отсутствии CA bootstrap предупреждает, а не скрывает проблему. Машинный
итог:

```text
KEENZOO_BOOTSTRAP_STATUS=ready|update-deferred|update-failed
```

## 16. Ограничение повторов `infinity_polling`

Сетевые переподключения TeleBot сохранены. Ограничена только запись
одинаковых `Infinity polling exception` в `error.log`:

- первая ошибка пишется сразу;
- повторы подавляются в течение 600 секунд;
- следующая разрешённая запись сообщает число подавленных повторов;
- остальные типы ошибок не фильтруются.

Интервал можно задать в `bot_config.py`:

```python
TELEBOT_LOG_THROTTLE_SECONDS = 600
```

Минимум — 60 секунд. При отсутствии или ошибочном значении действует
600 секунд.

## 17. Типовые проблемы

### SSH после `[5/5]` не открывается

1. Проверьте порты 222 и 22.
2. Используйте `root`, а не `admin`.
3. Найдите в системном журнале Keenetic строки `dropbear`.
4. `(config)>` означает CLI прошивки, а не Entware shell.

### Меню пишет «Entware не готова»

```sh
ls -l /opt/bin/opkg
mount | grep ' /opt '
/opt/bin/opkg update
```

### Проект предлагает изменить зеркало Entware

Сначала внимательно сравните показанные строки «Сейчас» и «Будет».
Проверьте текущую конфигурацию отдельно:

```sh
grep -E '^src/gz[[:space:]]+(entware|keendev)[[:space:]]' /opt/etc/opkg.conf
```

Если согласны с предложенным рабочим зеркалом, введите:

```text
SWITCH
```

Для отказа нажмите Enter или введите любое другое слово. При отказе
`opkg.conf` остаётся побайтно неизменным, а установка/обновление
останавливается до изменения проекта.

### Меню не находит архив

Для внутреннего меню архив должен находиться в `/tmp` и называться:

```text
KeenZOO_full_*.tar.gz
```

Проверьте:

```sh
ls -lh /tmp/KeenZOO_full_*.tar.gz
```

### После редактирования не запускается панель/бот

```sh
cd /opt/etc/bot
python3 -c 'import bot_config; print("bot_config OK")'
/opt/etc/init.d/S99generator restart
/opt/etc/init.d/S99telegram_bot restart
```

Если `bot_config.py` синтаксически сломан, редакция 23+ поднимает на
штатном порту аварийную 503-страницу с диагнозом и командами ремонта.

### Где смотреть журналы

```sh
tail -100 /opt/etc/bot/error.log
tail -100 /opt/etc/bot/generator.log
cat /tmp/unblock_update.log
```

Для запуска обновления из веб-панели правильный временный журнал —
`/tmp/unblock_update.log`.

## 19. Проверка этой редакции

Перед выпуском выполнены:

- `busybox ash -n` и `dash -n` для всех shell-скриптов проекта;
- функциональный стенд в изолированных mount namespace;
- E2E-диспатч всех пяти пунктов обоих меню;
- fail-closed проверки отсутствующей Entware, архива и проекта;
- безопасный smoke реального режима `deploy_bypass.sh -remove` на
